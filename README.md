# Ultramarine Plasma Settings

Maintained by Cypress Reed

Plasma System Settings modules and Discover integration for Ultramarine Linux, backed by [`umcli`](https://github.com/Ultramarine-Linux/um).

- **Updates** (`kcm_ultramarine_updates`): system, Flatpak and Nix updates.
- **Tweaks** (`kcm_ultramarine_tweaks`): optional Ultramarine system tweaks.
- **Discover patch** (`discover/`): routes Discover's Updates entry to the Ultramarine Updates KCM.
